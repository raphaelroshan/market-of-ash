# Market of Ash 0.15.0 — Investment Vertical Candidate

Version: `0.15.0-early-access-rc2`
Content: `1.27.0`
Save format: `12`
Engine: Godot `4.4.1` or newer

This candidate contains the complete Early Access investment vertical from RC1 and improves the regional Departure map used across all three regions. Route names now live in a compact, region-specific key below the map instead of colliding with settlement markers; the map heading is concise; destination detail appears only on actual pointer hover; and persistent itinerary cards remain the planning source of truth. Large Text continues to use the fully labeled itinerary cards without squeezing a second legend into the map.

The complete slice includes a readable opening, contract-free tutorial trade, route comparison, visible travel and consequences, market-memory receipts, optional black-market pressure, crew-aware endings, and a connected three-region economy. It contains ten settlements, ten goods, eight routes, five specialists, eight deterministic event families, four standing factions, two adaptive replacement actors, and six endings.

## Install

Download `market-of-ash-windows.zip`, verify it against `SHA256SUMS.txt`, and extract the complete `Market of Ash` folder to a writable location. Run `market-of-ash.exe`. The game is portable; campaign and settings data live in Godot's per-user application-data directory rather than beside the executable.

The standalone `market-of-ash.exe` asset contains the same embedded game pack, but the ZIP is recommended because it carries this guide beside the game.

## Upgrade and save compatibility

Back up the existing `Market of Ash` user-data folder before first launch. Save format 12 and content version 1.27.0 are unchanged from RC1. Existing RC1 and 0.14 campaigns remain compatible; this update changes presentation and test isolation, not simulation state.

## Rollback

Keep the previous portable folder until the upgraded campaign has loaded and saved successfully. To roll back, close the game, restore the backed-up user-data folder, and launch the previous executable. Do not open a save written by a newer save-format version in an older build; restoring the backup remains the safest path even though RC2 still writes format 12.

## Known limitations

- This is an unsigned prerelease candidate and may trigger SmartScreen or antivirus reputation warnings; verify its published SHA-256 checksums before running.
- Region, character, and route art is original code-native production scaffolding; final commissioned art and broader animation are not complete.
- Interface audio uses clearly attributed temporary CC0 assets.
- Physical-device, assistive-technology, antivirus-vendor, Steam, Epic Games Store, and moderated human-playtest certification remain external gates.
- The game has no cloud saves, localization, multiplayer, achievements, or online economy. Store services remain intentionally absent from the offline simulation.
