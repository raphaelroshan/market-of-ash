# Market of Ash 0.13.9 — Guide / Intel Audio Patch

This prerelease adds restrained page-opening feedback when entering the Bazaar's Guide / Intel stall.

## Changed

- Guide / Intel plays a short CC0 Kenney page cue when opened from another stall.
- Re-selecting the active stall does not replay the sound.
- The existing Interface Sounds preference disables the cue.
- The sound is decoded from an export-safe, provenance-recorded runtime copy.

No trade, route, event, campaign, save, or command behavior changed.

## Downloads

- `market-of-ash.exe` is the standalone Windows x86-64 build.
- `market-of-ash-windows.zip` is the recommended portable package.
- Integrity and provenance files accompany both downloads.
