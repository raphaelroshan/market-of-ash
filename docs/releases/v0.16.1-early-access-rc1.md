# Market of Ash 0.16.1 — Private Alpha Campaign

Version: `0.16.1-early-access-rc1`

Content: `1.28.0`

Save format: `12`

Engine: Godot `4.4.1` or newer

Recommended session: `30–90 minutes`

This private-alpha candidate packages the complete GPT56 investment slice: a clean New Game path, ordinary two-way trade, route comparison, in-between travel, authored contacts, arrival receipts, changing markets, optional black-market pressure, three complete regions, failure-forward replacement economies, and causal terminal reports.

This revision repairs the 1280×720 Introduction overflow found in the post-RC2 review. Opening layouts now negotiate against the real display bounds, preserve explicit horizontal safe areas, and keep wrapped copy and navigation inside the card at minimum width and Large Text.

The campaign contains eleven settlements, ten goods, nine roads, five specialists, nine deterministic event families, four standing factions, three adaptive replacement actors, and six endings. Contracts add deadlines and political value but remain optional; ordinary trade can reach profitable and terminal outcomes without them.

## Install

Download `market-of-ash-windows.zip` and `SHA256SUMS.txt` from the same GitHub release. Verify the ZIP checksum, extract the complete `Market of Ash` folder to a writable local location, and run `market-of-ash.exe`. Do not run the executable inside the ZIP.

The game is portable and operates offline. Campaign and settings files live in Godot's per-user `Market of Ash` application-data folder, not beside the executable. The standalone EXE contains the same embedded game pack, but the ZIP is recommended because it includes this guide.

## Upgrade and save compatibility

Before first launch, copy the existing `Market of Ash` user-data folder to a dated backup. Save format 12 is unchanged and migrates formats 0–11. Saves from content 1.27.0 and earlier load against the current stable IDs, acquire missing scenario defaults, and preserve valid cargo, routes, contracts, events, crew, endings, and replacement actors.

After upgrading, use Continue, inspect the day/cargo/settlement summary, make a manual save, return to title, and load once before deleting the backup. A successful save keeps one automatic `.bak` generation; if the primary is corrupt, Continue validates and uses that backup without rotating the corrupt file over it.

## Rollback

Keep the previous portable folder and the pre-upgrade user-data copy until the upgraded campaign has loaded and saved successfully. To roll back, close the game, replace the current user-data folder with the dated backup, and launch the previous executable.

Do not rely on an older build to understand state written by a future save-format version. Restoring the matching backup is the supported rollback path.

## Known limitations

- This is an unsigned private-alpha Windows build and may trigger SmartScreen or antivirus reputation warnings. Verify the SHA-256 files before running.
- Settlement, character, and route art is original code-native production scaffolding; it is not final commissioned art.
- Interface audio and departure dust use attributed temporary CC0 assets listed in `assets/temporary/manifest.json` and the repository's temporary-asset guide.
- The Ash Sifters currently expose one cooperation action; their opposition/reconciliation depth is smaller than the Well Commons and Night Market.
- Physical-device, assistive-technology, antivirus-vendor, storefront, and moderated comprehension certification remain external calibration gates.
- There are no cloud saves, localization, multiplayer, achievements, telemetry, accounts, online economy, or required network services.
