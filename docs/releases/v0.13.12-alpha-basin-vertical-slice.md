# Market of Ash 0.13.12 — Caravan Yard Roster

This prerelease turns the Caravan Yard from a plain action list into a readable three-person roster.

## Changed

- Nara Vey, Jorun Pale, and Tess Oryn each receive a distinct code-native portrait and accent.
- Every roster card shows role, availability or assignment state, personality, strategic lever, limitation, and the real recruit/assignment action.
- Bazaar section headings now match the active stall instead of retaining the generic opportunity heading.
- Hidden roster actions no longer enter the keyboard/controller focus cycle.
- Native capture coverage now includes the Caravan Yard at normal and Large Text sizes.

No crew rules, costs, benefits, save state, route calculations, or command behavior changed.

## Downloads

- `market-of-ash.exe` is the standalone Windows x86-64 build.
- `market-of-ash-windows.zip` is the recommended portable package.
- Integrity and provenance files accompany both downloads.

The Windows build remains unsigned and may display a reputation warning.
