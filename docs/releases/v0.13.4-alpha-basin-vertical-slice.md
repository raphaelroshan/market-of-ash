# Market of Ash 0.13.4 — Roadside Decision Dossier Patch

This prerelease keeps the complete Five-Well Basin vertical slice and improves the clarity of roadside encounters.

## Changed

- Encounter rails now lead with a compact threat dossier.
- Maximum cargo risk, exposed cargo value, route, dilemma, special event basis, and rules boundary are separated for faster scanning.
- Duplicate event title and setup copy is removed from the response rail because it remains visible in the persistent journey context and road narrative.
- Response readiness uses a shorter count while blocked choices continue to name their exact requirement.
- Every response retains its disclosed costs, cargo exposure, arrival behavior, and expected outcome.

No route trigger, event choice, outcome, economy, save, or command rule changed.

## Downloads

- `market-of-ash.exe` is the standalone Windows x86-64 build.
- `market-of-ash-windows.zip` is the recommended portable package.
- `SHA256SUMS.txt`, `release_manifest.json`, and `windows-version.json` provide integrity and provenance.

The Windows build remains unsigned and may display a reputation warning.

## Known limitations

- Procedural visuals remain alpha-quality rather than final commercial art.
- Physical-controller feel, Windows high-DPI devices, screen readers, antivirus reputation, and storefront launch behavior need human hardware testing.
- Moderated first-time-player sessions are still required to validate comprehension and enjoyment beyond deterministic and visual checks.
