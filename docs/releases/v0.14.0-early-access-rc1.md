# Market of Ash 0.14.0 — Early Access Candidate

Version: `0.14.0-early-access-rc1`  
Content: `1.26.0`  
Save format: `12`  
Engine: Godot `4.4.1`

This candidate completes the automated Early Access implementation roadmap: a
connected three-region trade sandbox with ten settlements, ten goods, seven
routes, five decision-changing crew members, eight deterministic event
families, four standing factions, two adaptive replacement actors, and six
endings.

## Install

Download `market-of-ash-windows.zip`, verify it against `SHA256SUMS.txt`, and
extract the complete `Market of Ash` folder to a writable location. Run
`market-of-ash.exe`. The executable is portable and stores campaign and settings
data in Godot's per-user application-data directory, not beside the executable.

The standalone `market-of-ash.exe` asset contains the same embedded game pack,
but the ZIP is recommended because it carries this guide beside the game.

## Upgrade and save compatibility

Back up the existing `Market of Ash` user-data folder before first launch. Save
format 12 is unchanged from the latest alpha. The loader migrates formats 0–11,
accepts prior content-version saves when their stable references remain valid,
and retains one automatic backup generation. New MA-EA-5 crew and event records
do not rewrite an existing campaign.

## Rollback

Keep the previous portable folder until the upgraded campaign has been loaded
and saved successfully. To roll back, close the game, restore the backed-up
user-data folder, and launch the previous executable. Do not open a save written
by a newer save-format version in an older build. This candidate still writes
format 12, but restoring the backup is the safest rollback path.

## What to test

- Start without guidance and complete a profitable ordinary-trade loop.
- Complete or ignore the Water Relief and Beacon Oil offers.
- Recruit Mara Voss at Blackreed Post and use her Reedline repair response.
- Resolve the Shardwind Tithe, then return to the Mirror Run with Orin Bell.
- Reach an ending, continue trading, and replay with another route or faction.
- Exercise keyboard, controller, Large Text, Reduced Motion, save, load, and
  pause/report flows.

## Known limitations

- This is a prerelease candidate, not a final commercial build.
- The Windows executable is unsigned and may trigger SmartScreen or antivirus
  reputation warnings. Verify the published SHA-256 checksums before running.
- Region, character, and route art is original code-native production
  scaffolding; final commissioned art and broader animation are not complete.
- Interface audio uses clearly attributed temporary CC0 assets.
- Physical-device, assistive-technology, antivirus-vendor, Steam, Epic Games
  Store, and moderated human-playtest certification remain external gates.
- The game has no cloud saves, localization, multiplayer, or online economy.

## Verification

The release workflow reruns the deterministic suite on Linux and Windows,
validates the release contract, exports Windows and Web builds, checks the PE
architecture and embedded PCK, clean-extracts and launches the portable ZIP,
captures the real Windows main menu and version metadata, records SHA-256
checksums and provenance, and publishes these files only after every step passes.
