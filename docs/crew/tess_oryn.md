# Tess Oryn — Negotiation Crew Proof

Tess is a fixer whose value is an explicit alternative inside a live event, not a passive discount.

- Recruit in Ashgate for 22 ashmarks and one visit slot.
- Assign or refresh her for one visit slot. Assignment competes directly with Nara and Jorun.
- While assigned, Gatekeeper's Chalk exposes `challenge_chalk_ledger` as an enabled response.
- The challenge costs one day, preserves cargo and cash, records the `gatekeeper_invented_tolls` lead, and lowers Warden standing by one.
- Without Tess assigned, the same response remains visible but disabled with the exact prerequisite.

This proves a crew-gated social choice through the existing event command boundary. It does not add a generic dialogue system, hidden persuasion roll, or full faction progression.
