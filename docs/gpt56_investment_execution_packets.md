## Packet MA-GPT56-1 — Complete creative vertical

Build one clean-save evaluation path from New Game through Introduction, first Bazaar purchase, route comparison, departure, road event/contact, arrival sale or recovery, changed return Bazaar, optional black-market pressure, and terminal economic/political receipt. The path must use normal player commands and must not call debug fixtures. Add a deterministic fixture that can reproduce the path from a named seed without bypassing commands. Keep ordinary trade viable and black-market activity optional.

Acceptance requires a player-facing action at every stage, visible pre-commit cost/risk, an arrival receipt that names what changed, a return market whose prices or access reflect the trip, save/resume parity at every phase, keyboard/controller focus, large text, reduced motion, and a 1600×900 capture sequence. Add one ordinary-trade-only success path and one black-market-pressure path; neither may invalidate the other.

Non-goals are new currencies, a mandatory contract chain, procedural prose, or moving price calculation into the UI. The authoritative owners remain `src/core/`, and the UI consumes read-only snapshots.

Acceptance requires a visual registry, no duplicate styling decisions scattered across panels, responsive captures at 1280×720 and 1600×900, focus and large-text checks, and one screenshot sequence proving that the same journey can be read from source settlement to return settlement.

## Packet MA-GPT56-3 — Market breadth and non-railroaded play

Author region-two and region-three content as compact, complete slices. Each region needs three settlements, three routes, three goods, one ordinary-trade pattern, one optional contract, one event family, one faction pressure, one failure-forward response, and one post-consequence opportunity. Run a 100-seed policy matrix before changing balance. Reject any slice whose only distinction is prose, a renamed good, or a higher price.

Acceptance requires at least four unrelated ordinary-trade patterns, no contract-required ending, a replacement actor after an ignored/failed scenario, rotated best plans across changed market states, save migration, and a readable report of player choices and consequences.
